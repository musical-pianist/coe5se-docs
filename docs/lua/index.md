# Lua

!!! info "Work in progress"
    The Lua section is still being written. Expect more pages and changes.

Script what a .c5m can't. Custom screens, hotkeys, scripted campaigns and smarter AI are all possible with Lua in CoE5SE.

Lua in CoE5SE is still the wild west. For now this section covers LAN games only. Every function, with its arguments and returns, is annotated in [`coe5.lua`](https://github.com/musical-pianist/coe5se/blob/main/coe5.lua); put it in your workspace for completion and hovers in any editor running the Lua language server. The language itself: the [Lua 5.5 manual](https://www.lua.org/manual/5.5/).
